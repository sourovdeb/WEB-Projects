## GitHub Pages

This project needs no build step.

Copy the contents of `dist/` into the root of a GitHub Pages repository. Then choose **Deploy from a branch** in repository settings. Select the relevant branch and root folder.

## Local preview

Open `dist/index.html` in a browser.
